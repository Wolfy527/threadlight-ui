# ThreadLight UI

Shared editor theme, controls, and branding used by ThreadLight Components and Authoring. Installed automatically with those packages or their generated fallback installer.

Editor tools share `ThreadlightDisclosureElement` (custom headers), `ThreadlightDisclosureCard` (standard folders), and `ThreadlightColumnLayout` (retained responsive cards). Supply content, accents, and state callbacks; keep input, reveal animation, and layout in the shared controls. `CreateResponsiveGrid` preserves each folder frame in its own slot, and `BindFooterInset` reserves measured footer space.
